# Contracts 1.2.0: level 1 needs a source; [inferred] never reaches it by audit

## Why

C3 defines level 1 as "passed audit (sampled and confirmed, or in an audited population with no contradiction)". For an `[inferred]` criterion, "confirmed" was the fact-checker's NOT-CONTRADICTED: a guess nothing contradicted counted the same as a fact a source states, and a clean `[inferred]` sample raised every unsampled `[inferred]` criterion too. rspec now stops producing that (tammai/rspec PR #10, `audit_sample.py --levels`); this brings the contract's wording to the same rule, so every consumer reads level 1 the same way.

**Request (verbatim):** "the contracts is from product rebuild" (the follow-up to rspec PR #10, whose change file left "the C3 wording in the contracts' source" out of scope). Version chosen by the user: **1.2.0**.

## Decisions

| Decision | Ruled out | Why |
|---|---|---|
| 1.2.0 (minor) | 1.1.2 (patch); `v2/` (major) | A rule change consumers should notice (a lock with an `[inferred]` criterion at level 1 no longer conforms), but no field or format changes. The user chose it |
| Wording only; `contracts.py lock` gets no new check | An error for `tag: inferred` with `level: 1` | Not asked for. Proposed below |
| Level 2 for `[inferred]` stays allowed | Forbidding it | A recorded test passing against the reference is evidence in its own right |
| The evals' fixture locks keep `"contracts": "1.1.1"` | Bumping them | `contracts.py lock` doesn't compare that field with `VERSION`; they test the pipeline, not the version |

**Proposals not asked for:** `contracts.py lock` reports `error` for a criterion tagged `inferred` at level 1, making the rule mechanical. Dropped unless the user keeps it.

## Acceptance criteria

- **AC-001** Given `contracts/v1/` at 1.2.0, when `contracts.py vendor-check` and the version test run, then `VERSION` is 1.2.0, every file carries the `contracts-version: 1.2.0` header and MANIFEST matches.
- **AC-002** C3's level line says level 1 needs a SUPPORTED verdict when sampled (or an unsampled place in a population whose sample has no contradiction), and that an `[inferred]` criterion never reaches level 1 by audit.

- The `contracts.py lock` check above, unless kept.
